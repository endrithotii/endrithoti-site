Projects

Second Read

Literature surveillance where every model answer is checked twice.

Every morning it searches PubMed for new papers on one question, then:

  1. a first model screens each paper and extracts its key facts, each with a quote;
  2. plain code checks every quote is in the paper word for word and every number matches;
  3. a second model, from a different company, re-reads the paper and judges every claim;
  4. two differently built searches estimate how many relevant papers both missed.
