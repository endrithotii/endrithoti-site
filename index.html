What my literature monitor did on its latest run

It read 37 new papers on resistance to the lung-cancer drug osimertinib. 9 passed every check, 19 went to a person with the reason, and it estimates 6 relevant papers were missed.

Second Read is a project of mine. One AI model extracts the facts from each new PubMed paper. Plain code then checks that every fact is quoted word for word from the paper, and a second model from a different company re-reads it. Only what both checks pass is accepted.
